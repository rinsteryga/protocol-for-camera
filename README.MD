# Архитектура VideoSender (Сервер трансляции)

Приложение реализует захват видеопотока с веб-камеры, его обработку, фрагментацию и отправку по протоколу UDP в реальном времени. Архитектура построена на базе Qt 6 (Multimedia, Network, Quick) с разделением вычислительной нагрузки по потокам.

## Пайплайн данных (Data Flow)
`QVideoSink` (Камера) -> `QVideoFrame` -> `QImage` -> `QByteArray` (нарезка на `PacketData`) -> `QUdpSocket` (Отправка по сети).

---

## 1. Протокол передачи данных (`Packet.hpp`)

Описывает структуру датаграмм для передачи сырых кадров. Упаковка данных происходит без выравнивания (`#pragma pack(1)`).

* **`PacketHeader` (Заголовок 15 байт):**
  * `type` (`MsgType`): Тип сообщения (VideoFrame).
  * `frameId` (`quint32`): Глобальный инкрементальный идентификатор кадра.
  * `fragmentIdx` (`quint16`): Индекс текущего фрагмента в кадре.
  * `totalFragments` (`quint16`): Общее количество фрагментов кадра.
  * `imgWidth`, `imgHeight` (`quint16`): Разрешение передаваемого кадра.
* **`PacketData` (Сериализация):**
  * `toQBA()`: Формирует бинарный пакет (`QByteArray`), вычисляет контрольную сумму (`qChecksum`) и вшивает заголовок.

---

## 2. Логика приложения

### `VideoSender` (Менеджер захвата в GUI-потоке)
* **Функционал:** Управляет аппаратным захватом через `QMediaCaptureSession` и `QVideoSink`. 
* **Обработка кадра:** Метод `processLocalFrame` перехватывает сырой `QVideoFrame`, копирует его из VRAM в оперативную память (`map(QVideoFrame::ReadOnly)`), конвертирует в `QImage` (RGB32), выполняет downscale до 320x240 для стабильности UDP и асинхронно передает в Worker-поток.

### `SenderWorker` (Сетевой поток)
Живет в отдельном `QThread`, чтобы нарезка байтов не вызывала фризы интерфейса.
* **Инициализация:** Открывает `QUdpSocket` и принудительно расширяет системный буфер ОС (`SendBufferSizeSocketOption`) до 8 МБ для предотвращения локальных дропов пакетов.
* **Фрагментация:** Вычисляет размер полезной нагрузки, нарезает сырой массив пикселей (`img.constBits()`) на чанки по 1000 байт и в цикле отправляет их на целевой IP и порт (5555) с помощью `writeDatagram`.

---

## 3. Пользовательский интерфейс (QML)
Интерфейс написан на Qt Quick. Содержит:
* `VideoOutput` для локального предпросмотра захватываемого видео.
* `ComboBox` для динамического переключения между доступными веб-камерами (`QMediaDevices`).
* Кнопку управления состоянием трансляции (Start/Stop).
