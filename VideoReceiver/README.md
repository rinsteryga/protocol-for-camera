# Архитектура VideoReceiver (Клиент трансляции)

Приложение реализует прослушивание UDP-порта, сборку фрагментированных видеокадров из сети (с устойчивостью к потере пакетов) и их рендеринг в графическом интерфейсе. Архитектура построена на базе Qt 6 (Network, Quick) с разделением сетевой и графической логики по потокам.

## Пайплайн данных (Data Flow)
`QUdpSocket` (Прием) -> `FrameBuffer` (Сборка с учетом потерь) -> `QImage` -> `QProperty` -> `QmlImageItem` (Отрисовка в QML Canvas).

---

## 1. Протокол передачи данных (`Packet.hpp`)

* **`PacketHeader`:** Содержит метаданные фрагмента (`frameId`, индекс фрагмента, разрешение кадра).
* **`PacketData` (Десериализация):**
  * `fromQBA()`: Статический метод. Читает входящий `QByteArray`, проверяет его размер и валидирует контрольную сумму (`qChecksum`). Если пакет битый, он отбрасывается (возвращается `std::nullopt`).

---

## 2. Сетевое ядро

### `ReceiverWorker` (Сетевой поток)
Живет в отдельном `QThread`. Изолирует сетевой стек от цикла событий UI.
* **Прием данных:** Слушает порт 5555 на всех интерфейсах (`AnyIPv4`). Буфер приема ОС увеличен до 8 МБ (`ReceiveBufferSizeSocketOption`).
* **Сборка (Lossy Assembly):** Пакеты сохраняются в хэш-таблицу `std::unordered_map` по ключу `frameId`. Вектор данных преаллоцируется нулями (черный цвет) при получении первого фрагмента. Байты копируются строго по смещению (`fragmentIdx * CHUNK_SIZE`).
* **Управление потерями (Drop Handling):** UDP не гарантирует доставку. Если приходит пакет от *более нового* кадра, Worker принудительно завершает сборку старого кадра. Потерянные пакеты остаются черными пикселями. Старый кадр отправляется на экран, предотвращая рассинхронизацию видеопотока и утечки памяти.

---

## 3. Графический интерфейс и Рендеринг

### `VideoReceiver` (Менеджер интерфейса)
Служит мостом (Context Property) между C++ и QML. Принимает склеенный `QImage` из Worker-потока, обновляет Q_PROPERTY `currentFrame` и уведомляет QML-движок.

### `QmlImageItem` (Кастомный рендер в QML)
Наследуется от `QQuickPaintedItem`.
* **Назначение:** Обходит ограничения стандартного QML `Image`, позволяя рендерить плюсовый класс `QImage` напрямую в графе сцены без использования кэшируемых URL-провайдеров.
* **Отрисовка:** Переопределенный метод `paint(QPainter *painter)` масштабирует кадр с сохранением пропорций (`Qt::KeepAspectRatio`) и выводит его на экран с высокой производительностью и без мерцания.
